## Entry

> Please send the revised contract to my assassin, she handles all my paperwork now.

One line, 82 characters. The slip is a single wrong word: **assassin** for **assistant** — a work email that reads perfectly normally until the one word that makes it a crime scene.

## How it works

`main.ts` is deterministic and makes no network calls. It writes the entry — exactly one line, under 200 characters, with no trailing newline — to `/output/entry.txt`.
